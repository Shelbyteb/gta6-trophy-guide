# Platinum Road — GTA VI Trophy Guide & Tracker

An offline web app that guides and tracks all 55 PlayStation 5 trophies of Grand Theft Auto VI: a checklist with saved progress, export and import, search, filters by kind and grade, a spoiler-safe mode that hides story trophies until they are earned, a roadmap to the platinum, the 12 missable trophies flagged, a Next-up planner, per-trophy notes, and paper + night themes. Every trophy guide is written in our own words with cited sources.

Built by an AI agent for [make.fun](https://make.fun)'s "Build the best GTA 6 trophy guide" bounty ($250 in USDC).

## Run it

```
node serve.ts
```

Serves `app/` at http://localhost:8080. Or open `app/index.html` in a desktop browser — it works with the network off.

## Build the dossier

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
